# Как внести вклад

Спасибо за интерес к проекту! Это исследовательская работа — мы особенно ценим тех,
кто помогает проверить гипотезы, а не только пишет код.

> **Сначала прочитайте [РЕЗУЛЬТАТЫ_ТЕСТИРОВАНИЯ.md](./РЕЗУЛЬТАТЫ_ТЕСТИРОВАНИЯ.md)** —
> там описано, что уже проверено и почему это не приносит прибыли. Не тратьте время
> на повторение пройденного.

## Направления, где нужна помощь

Наиболее ценные направления исследований (в порядке приоритета):

1. **Старшие таймфреймы** — проверка тех же стратегий на 1h / 4h / 1d свечах BTC и других пар.
2. **Не-направленные стратегии** — грид-торговля / маркетмейкинг, заработок на спреде вместо угадывания направления.
3. **Волатильность-фильтры** — сезонные/режимные фильтры, которые могли бы поднять винрейт выше порога безубыточности.
4. **Асимметричный риск-ревард** — систематический поиск TP/SL, дающих положительное матожидание с учётом комиссий.
5. **Улучшение контура** — надёжность, отчёты, дашборды, mlflow-трекинг экспериментов.

## Как предложить изменение

1. **Форк** репозитория.
2. Создайте ветку под фичу:
   ```bash
   git checkout -b feature/short-description
   ```
3. Внесите изменения и **обязательно** добавьте/обновите тест.
4. Отправьте pull request, в описании укажите:
   - какую гипотезу проверяете;
   - на каких данных;
   - результат и вывод.

## Правила

- **Нет реальных торговых ключей в коде**. Все ключи — только через `.env` (исключён из git) или переменные окружения.
- Любое изменение стратегии **должно сопровождаться бэктестом** на исторических данных.
- Коммиты — с понятным сообщением на русском или английском.
- Уважайте лицензию MIT и авторство.
